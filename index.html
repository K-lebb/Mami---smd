Módulo 01

RGB & HEX

Uma cor digital é um vetor tridimensional (R, G, B), onde cada componente vai de 0 a 255. O código hexadecimal é a mesma informação escrita em base 16.

A razão de contraste entre texto e fundo é calculada a partir da luminância relativa das cores — uma proporção que garante legibilidade. A WCAG recomenda mínimo de 4.5:1 para texto normal.

Módulo 05

Estatística dos Tons de Cinza

Cada pixel pode ser convertido em um tom de cinza pela combinação linear 0.299·R + 0.587·G + 0.114·B. A partir disso calculamos média, variância e desvio padrão — medidas matemáticas que revelam o contraste e a distribuição tonal de uma imagem.

📷 Imagem 1 Clique ou arraste uma imagem
📷 Imagem 2 (opcional) Clique ou arraste uma imagem
📐 Como a matemática aparece aqui

Tom de cinza: T = 0.299·R + 0.587·G + 0.114·B

Média: μ = (1/N) · Σ Ti

Variância: σ² = (1/N) · Σ (Ti − μ)²

Desvio padrão: σ = √σ²

Quanto maior a variância, mais espalhados estão os tons — ou seja, maior é o contraste interno da imagem.
